# Gender Trends in the Global Workforce

## Data Source
IMF Gender Statistics: https://data.imf.org/en/datasets/IMF.STA:GS_LI

## How to Run Locally

1. Clone the repository:
   git clone https://github.com/YilinJoeyChi/gender-workforce.git
   cd gender-workforce

2. Install dependencies:
   pip install -r requirements.txt

3. Run the app:
   python app.py

4. Open your browser and go to:
   http://127.0.0.1:8050
